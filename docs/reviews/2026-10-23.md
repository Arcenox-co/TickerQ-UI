## Corrections made

- The Quick Start, Define Jobs, and code-defined cron examples now use tabs. The first/default
  tab is `ITickerFunction`; `[TickerFunction] attribute` is the second complete path.
- Function Registration now gives both methods their own section and keeps delegate registration
  as the third choice.
- Runtime XML comments and missing-registration diagnostics use the same two supported paths as
  the docs instead of instructing every user to add an attribute.
- Time/cron operation references include the in-place chain/occurrence retry methods already
  present in the public manager interfaces.
- Dashboard configuration now documents `SetLogoUrl` and `SetGroupName`; AI investigation setup
  names `WithMaxLogLines`, `WithMaxChainSteps`, and `UseSourceContextProvider`.
- The OpenTelemetry guide no longer reports the fixed optional-package enqueue-counter omission.

## Public API follow-up

`DashboardOptionsBuilder.WithSessionTimeout(int)` currently changes the session-timeout value
returned by dashboard auth metadata, but the bundled UI does not consume that value and the method
does not alter JWT `AccessTokenLifetime` or cookie `SessionLifetime`. It remains undocumented here
to avoid implying an enforcement guarantee. Decide separately whether to remove/deprecate that
legacy option or give it one precise runtime meaning.
