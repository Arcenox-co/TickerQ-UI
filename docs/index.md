features:
  - title: Zero-Reflection Core
    details: Source generators wire up handlers at compile time — no reflection, no startup cost. Fully AOT compatible.
  - title: Cron & One-Off Jobs
    details: 6-part cron expressions with second-level precision. Programmatic one-off scheduling with retries, priorities, and job chaining.
  - title: EF Core or Redis Storage
    details: Database persistence with migrations and LINQ queries, or Redis for fast in-memory storage. Both implement the same provider — swap in one line.
  - title: Dashboard & Multi-Node
    details: Vue.js + SignalR dashboard for live monitoring and CRUD. Redis-based distributed locking, heartbeats, and dead-node cleanup across nodes.
