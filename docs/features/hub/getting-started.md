# Getting Started with TickerQ Hub

This guide walks you through creating your account and getting set up with TickerQ Hub.

## Create an Account

1. Visit [hub.tickerq.net](https://hub.tickerq.net)
2. Click **Sign Up** or **Get Started**
3. Enter your email address and create a password
4. Verify your email address via the confirmation link
5. Complete your profile setup

::: tip
Use a work email for team collaboration features.
:::

## Sign In

Once your account is created:

1. Go to [hub.tickerq.net](https://hub.tickerq.net)
2. Enter your email and password
3. Click **Sign In**

## Dashboard Overview

After signing in, you'll see your Hub dashboard with:

- **Applications** - Your registered TickerQ applications
- **Nodes** - SDK instances connected to each application
- **Activity** - Recent registration and sync events
- **Settings** - Account and API configuration
