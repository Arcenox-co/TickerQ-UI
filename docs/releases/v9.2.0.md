# v9.2.0

**Release Date:** March 2026
**.NET Target:** .NET 9
**Equivalent Versions:** [v10.2.0](./v10.2.0) | [v8.2.0](./v8.2.0)

::: tip Version Parity
This release contains the same features and fixes as v10.2.0 and v8.2.0, targeting .NET 9. See [v10.2.0](./v10.2.0) for the full changelog.
:::

## Highlights

- **Per-function concurrency control** via `[TickerFunction("Name", maxConcurrency: 1)]`
- **CronTicker `IsEnabled` property** — disable/enable from dashboard or code
- **Dashboard timezone-aware date formatting** — EU, US, and ISO formats
- **Redis disabled ticker filtering** — consistency across all persistence providers
- **15+ bug fixes** including CSP compliance, design-time DbContext, MySQL type mapping, and more
